    Class StealthGuardClient

    StealthGuard telemetry collector (SPEC §6.2). Attaches global keyboard / pointer / touch listeners, buffers bounded event arrays, and flushes them to the gateway on an interval, on demand, and via sendBeacon on unload.

    Framework-agnostic core; the React hook (useStealthGuard) is a thin adapter.
